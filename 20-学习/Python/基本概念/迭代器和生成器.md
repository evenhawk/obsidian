# Python 迭代器和生成器
***
## 迭代器
迭代是访问集合元素的一种方式
`iter()` 和 `next()` 是两个常用的内置函数；迭代器本身需要实现 `__iter__()` 和 `__next__()`
字符串、列表、元组都可以创建迭代器
```python
numbers = [1,2,3,4,5]
it = iter(numbers)
print(next(it))
print(next(it))
```
输出结果为
```python
1
2
```
迭代器会自动按照顺序输出，而且直到遍历完所有的元素之前只会前进
同时也可以使用`for`循环来输出、
```python
numbers = [1,2,3,4,5]
it = iter(numbers)  # 创建迭代器
for i in it:  # 遍历迭代器
	print(i)
```
输出
```python
1
2
3
4
5
```

## 生成器
### 什么是生成器
生成器本质为一个特殊的迭代器，使用的时候才会生成下一个值
对比普通列表
* `ls = [x for x in range(100000)]` 一次生成全部数据，占用大量内存
* `ls = (x for x in range(100000))` 是生成器表达式，按需生成元素，不会一次性保存整个序列

### 生成器的创建方式
1. 使用小括号来创建 `()`
语法和[[推导式]]几乎一致，只是`[]`换成`()`
2. 使用带 `yield` 的生成器函数
	* 普通函数使用`return`,执行完销毁
	* 生成器函数使用 `yield`，保留当前状态
```python
def num(i):
	while i > 0:
		yield i
		i-=1

n = num(5)
print(next(n))
print(next(n))

for x in n:
	print(x)
```
输出结果
```Python
5
4
3
2
1
```

> 迭代器被耗尽后继续调用 `next()` 会抛出 `StopIteration`；`for` 循环会自动处理这个异常。
