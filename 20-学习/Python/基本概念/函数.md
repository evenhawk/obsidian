# Python 函数

## 函数定义
***
函数是组织好的可重复使用的实现特定功能的代码块
函数的定义由`def+函数名(参数):`组成
最后可以选择返回值return的数据
详情可看[[Python lambda匿名函数]]
```python
def add(a,b):
	c = a+b
	return c
```
上面这个函数能计算传入参数的和并返回

## 函数调用
***
定义了一个函数后,可以在另一个函数进行调用
在另外一个文件你也可以用`import`来进行引用

## 参数传递
***
在Python中对象有类型,但是变量没有
变量是一个指针
`ls = [1,2,3]`中的`[1,2,3]`是List类型,但`ls`没有类型
### 可更改对象和不可更改对象
在Python中字符串,元组,数字是不可变对象
相对的列表,字典是可以被修改的对象

### python不可变对象
通过`id()`来查看内存地址的变化
当你给参数赋新值的时候,内存地址就会变化
```python
a = 0
print(id(a))
a = 1
print(id(a))
```
输出结果如下
```
140708513096792
140708513096824
```
可以看见在赋值前后指针所指的地址变化了

### 可变对象
可变对象在函数调用中修改了值,那么它在函数外的值也会一起被修改

## 参数
***
参数类型有
* 必须参数
* 关键字参数
* 默认参数
* 不定长参数
### 必须参数
必须参数需要以正确的顺序传入函数,要和定义时一样
```python
def adds(a, b):
	a = a+1
	b = b+2
	print(a,b)
	return

adds(2,4) # 本来想得到3和6的需要按顺序输入,不然会得到5和4
```
### 关键字参数
外观上就是普通参数,但是你在输入时可以指定,只要指定了就和顺序无关了
```python
def printme(str):
	print(str)
	return

printme(str = "打印") # 括号里面的就是关键字指定
```

### 默认参数
当调用函数时,你想让一个参数有默认值就可以使用默认参数
使用默认参数的参数可以不填,会自动按照默认值输入
```Python
def printnameage(name, age = 18):
	print(name, age)
	return
printnameage("ash")
# 输出结果为
ash 18

```
当然你也可以在使用函数的时候修改默认参数

### 不定长参数
当你需要一个函数能处理比声明时更多的参数,你可以使用不定长参数
和上面两种参数不同,不定长参数声明的时候不会命名
在参数名前面加上`*`号来使这个参数变成不定长参数
```python
def function(parameter,*vartuple):
	print(parameter)
	print(vartuple)
	
function(1,2,3,4,5)

# 输出结果
1
(2,3,4,5)
```
不定长参数的值会自动被设为元组

*还有一种加两个`*`的参数会以字典的形式写入*
```Python
def function(a, **b):
	print(a)
	print(b)
function(1, c=1, d=2)

# 输出结果
1
{'c':1,'d':2}
```
当然多出的参数也会以字典的形式输出

## 匿名函数
***
Python使用`lambda`来创建匿名函数
匿名表示它没有函数名，通常作为一次性表达式使用，也可以赋值给变量
### 语法
lambda语法示例如下
```Python
x = lambda a : a + 10
print(x(5))

# 输出结果
15
```
它也等价于
```python
def x(a):
	a=a+10
	return a 

print(x(5))
```
