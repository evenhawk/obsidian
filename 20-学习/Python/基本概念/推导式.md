# Python 推导式
***
推导式可以在一行内写出类似for循环生成列表、字典、集合的结构体
## 列表推导式
列表推导式格式为
下面这个程序会生成一个1到99中偶数的列表
```python
[表达式 for 变量 in 列表 if 条件]
# 比如
ls = [i for i in range(1,100) if i%2==0]
```
筛选出名字长度大于3的人名，并将字母全部大写
```python
names = ['bob','tom','alice','rick','smith']
namels = [name.upper() for name in names if len(name)>3]
print(namels)
```

## 字典推导式
[[数据结构#字典|字典数据结构]]
字典推导式和[[#列表推导式]]的语法差不多，只是将`[]`换成了`{}`
使用字符串及其长度创建字典：
[[数据结构#5.字典推导式|字典推导式代码]]
```python
listdemo = ['Google','Runoob', 'Taobao']
# 将列表中各字符串值为键，各字符串的长度为值，组成键值对
>>> newdict = {key:len(key) for key in listdemo}
>>> newdict
{'Google': 6, 'Runoob': 6, 'Taobao': 6}
```
提供三个数字，以三个数字为键，三个数字的平方为值来创建字典
```python
>>> dic = {x: x**2 for x in (2, 4, 6)}
>>> dic
{2: 4, 4: 16, 6: 36}
>>> type(dic)
<class 'dict'>
```

## 集合推导式
集合推导式就像没有键值对的字典推导式
计算数字 1,2,3 的平方数：
```python
setnew = {i**2 for i in (1,2,3)}
print(setnew)
# 输出
{1, 4, 9}
```
判断不是 abc 的字母并输出：
```python
a = {x for x in 'abracadabra' if x not in 'abc'}
print(a)
# 输出
{'d', 'r'}
```

## 生成器表达式
圆括号形式的“推导式”实际上是生成器表达式，可以利用 range、元组、列表、字典和集合等数据源，按需生成值。
生成器表达式返回一个[[迭代器和生成器#生成器]]对象，而不是元组；如果需要元组，可以使用 `tuple(...)` 转换
```python
a = (a for a in range(1,10))
print(next(a))
print(next(a))
# 输出
1
2
```


> `tuple(a for a in range(1, 10))` 会一次性创建元组；直接保留生成器表达式则更节省内存。
