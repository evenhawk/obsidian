# Python 方法和函数的区别

## 定义
***
>函数(function):独立存在的代码块,**不属于任何类和对象**
>方法(method):**定义在类内部**的函数,与某个类和对象绑定

## 核心区别
***
### 调用方式不同
```python 
def my_func():
    print("我是函数")

class MyClass:       # 方法在类底下定义
    def my_method(self):
        print("我是方法")

# 函数：直接调用
my_func()

# 方法：必须通过实例或类调用
obj = MyClass()
obj.my_method()      # 通过实例调用（绑定方法）
```
函数直接调用
方法通常通过实例调用，也可以通过“类名.方法(实例)”的方式调用
### 方法会自动接收 `self`
```Python
class Dog:
    def bark(self):       # 实例方法第一个参数是 self（代表当前对象）
        print("汪汪")

d = Dog()
d.bark()                  # 实际等价于 Dog.bark(d) —— Python 自动把 d 传给 self
```
函数没有这个机制，除非你手动传
```Python
def bark(self):           # 普通函数也可以写 self，但不会自动传入
    print("汪汪")

bark()                    # ❌ TypeError: 缺少参数
```

### 类方法、静态方法和实例方法

- 实例方法：第一个参数通常是 `self`，通过实例调用。
- 类方法：使用 `@classmethod`，第一个参数通常是 `cls`，既可通过类调用，也可通过实例调用。
- 静态方法：使用 `@staticmethod`，不会自动接收 `self` 或 `cls`，主要用于组织与类相关但不依赖实例状态的函数。
