# 层级关系
Modbus-RTU(应用层)→ UART/USART(时序层)→ TTL/RS-232/RS-485/RS-422(物理层)

# 介绍

TTL/RS-232/RS-485/RS-422都是串行电气接口标准

# TTL和RS-232

_TTL和RS-232都是单端信号_
信号只有一根数据线，参考点是公共 GND（地），电压是**信号线对地**的电压。

## TTL的电平对比RS-232的电平

**使用场景:** TTL一般用于单片机和嵌入式的串口

- 输出低电平时,电压为0V,表示逻辑0
- 输出高电平时,电压为3.3V,表示逻辑1

**使用场景:** RS-232用于工业生产

- 输出低电平时,电压为-15V,表示逻辑1
- 输出高电平时,电压为+15V,表示逻辑0

_对比发现有两个区别_

第一是电压差
TTL电平因为是嵌入式芯片使用,所以电压差较低,峰峰值只有3.3V
RS-232的峰峰值有30V,因为主要用于工业使用,高电压差可以保证长距离传输的稳定性

第二是逻辑相反
TTL在输出高电平的时候输出的是逻辑1,输出低电平的时候输出逻辑0,简化逻辑电路
而RS-232刚好相反,因为RS232 空闲时保持负电压（Mark=1）一旦断线、驱动器失效，线路变成高阻浮空,更容易判断断线

# RS-422和RS-485

_RS-422和RS-485为差分信号_
两根信号线（A/B），看两根线之间的差值，不依赖对地电位。
