# Markdown 介绍
Markdown 的核心特点包括：
**简洁性**：使用直观的符号来表示格式，比如用 `#` 表示标题，用 `*` 表示列表项。这些符号在视觉上就能传达其含义，即使不进行渲染也具有良好的可读性。
**可读性**：即使是纯文本形式的 Markdown 文档，也能清晰地展现文档的结构和层次。读者无需专门的软件就能理解内容的组织方式。
**便携性**：Markdown 文件是纯文本格式，可以在任何文本编辑器中打开和编辑，不依赖特定的软件或操作系统。
**转换性**：可以轻松转换为 HTML、PDF、Word 文档等多种格式，满足不同的发布需求。

# 标题的格式


markdown一共有六级不同的标题
使用不同数量的#号来编写
``` markdown
# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题
```
下面是这串代码的实际效果，注意#和文字中间需要空格。
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

# Markdown文本格式
## 字体
***
Markdown 可以使用**粗体**和*斜体*。

1. *斜体语法*：使用一个星号包围文字 
```markdown
这是*斜体文字*使用一个星号
```

2. **粗体语法**：使用两个星号包围文字
```markdown
这是**粗体文字**使用两个星号
```

3. ***粗斜体组合***：使用三个星号包围文字
```markdown
这是***粗斜体文字***使用三个星号
```
## 分隔线
***
- 在行内使用三个星号来画出分隔线。
```markdown
# 下面这条线由这三个星号画出
***
```
***

## 删除线
***
- 如果要在一个~~单词~~上这样划线，使用两个~来进行划去。
```markdown
# 划去一段文本,代码和效果如下
~~划去这一句话~~
```
~~划去这一句话~~

## 下划线
***
下划线可以通过 HTML 的`<u>`和`</u>`标签包围来实现：
```markdown
# 下划线代码和效果如下
<u>下划线</u>
```
<u>下划线</u>

## 脚注
***
脚注是对文本的补充说明。
Markdown 脚注的格式如下:
```markdown
# 脚注代码和效果如下
要注明的文本[^脚注]
```
要注明的文本[^脚注]
这个要在阅读模式里看才有效

[^脚注]:还可以在文后看解释，可以点击跳转，上面会自动加一条分隔线。
## 行内代码标记
***
行内代码用于在正文中标记代码片段、命令、变量名等：
1.  使用一个反引号来包围文本
```markdown
# 代码和效果如下
`代码文本`
```
`代码文本`
2. 如果代码文本本身包含反引号，外层可以使用更多反引号：
````markdown
``` `代码文本` ```
````

## 文本高亮
***
高亮文本使用两个=号来包围==要高亮的文本==
```markdown
# 代码和效果如下
==高亮文本==
```
==高亮文本==

# Markdown 列表
Markdown 支持**有序列表**和**无序列表**。
***
## 无序列表

无序列表使用星号、加号、减号 作为列表标记，这些标记后面要添加一个空格，然后再填写内容
```markdown
* 第一项
* 第二项
* 第三项

+ 第一项
+ 第二项
+ 第三项


- 第一项
- 第二项
- 第三项
```
这上面的代码输出的效果一致如下，一般建议使用减号。
* 第一项
* 第二项
* 第三项
## 有序列表
***
有序列表使用数字并加上 . 号来表示，如：
```markdown
# 代码和效果如下
1. 列表一
2. 列表二
3. 列表三
```
1. 列表一
2. 列表二
3. 列表三
数字可以不连续，但是markdown会自动修正。

## 列表嵌套
列表可以嵌套使用，创建多层次的结构：
***
### 无序嵌套列表
```markdown
- 水果
  - 葡萄
    - 紫葡萄
    - 青提
  - 香蕉
  - 橙子
- 蔬菜
  - 胡萝卜
  - 白菜
```
- 水果
  - 葡萄
    - 紫葡萄
    - 青提
  - 香蕉
  - 橙子
- 蔬菜
  - 胡萝卜
  - 白菜

### 有序嵌套列表
```markdown
1. 准备阶段
	1. 收集资料
	2. 制定计划
3. 执行阶段
	1. 开始实施
	2. 监控进度
4. 总结阶段
```
1. 准备阶段
	1. 收集资料
	2. 制定计划
2. 执行阶段
	1. 开始实施
	2. 监控进度
3. 总结阶段
在嵌套有序列表时，为了防止自动排序，子列表前需要缩进。

### 混合嵌套列表
```markdown
1. 主要任务
	   - 子任务A
	   - 子任务B
	     1. 详细步骤1
	     2. 详细步骤2
	   - 子任务C
2. 次要任务
```
1. 主要任务
	   - 子任务A
	   - 子任务B
	     1. 详细步骤1
	     2. 详细步骤2
	   - 子任务C
2. 次要任务
列表混合嵌套只需在子列表中的选项前面添加一个或两个缩进即可。

### 任务列表
任务列表由一个 - + [ ] 组成，注意中间要插三个空格，[x] 表示完成。
```markdown
代码和效果如下所示
- [ ] 未完成的任务
      - [ ] 嵌套任务1
- [x] 完成的任务
```
 - [ ]  未完成的任务
      - [ ] 嵌套任务1
- [x] 完成的任务

# Markdown代码
***
## 行内代码
如果是段落上的一个函数或片段的代码可以用反引号把它包起来`like this`
```Markdown
`print()`
```

## 代码区块
### 缩进式代码块
使用一个制表符（Tab）或四个空格来表示缩进
```Markdown
正常文本段落

    这是缩进式代码块
    每行前面有四个空格
    保持代码的原始格式

继续正常文本
```

### 三反引号代码块
你可以用上下两行三个反引号来创建多行代码块：
````markdown
```python
print("hello")
```
````

# Markdown 链接
***
## 普通链接
链接是使 Markdown 文档具有交互性的关键元素。
掌握链接语法能让你创建内容丰富、易于导航的文档。
链接使用方法如下：
```markdown
# 格式如下
[哔哩哔哩 (゜-゜)つロ 干杯~-bilibili](https://www.bilibili.com/)
```

[哔哩哔哩 (゜-゜)つロ 干杯~-bilibili](https://www.bilibili.com/)
点击可跳转
## 参考链接
可以用两个`[]`来设置参考链接
such as 
```markdown
[Google][1]
# 在文后写网址
[1]: http://www.google.com/
```

这个链接用 1 作为网址变量 [Google][1]

  [1]: http://www.google.com/

## 如何引用另一篇文档然后自定义文字
* 格式
		使用`[[文档名#其中某一章|你要显示的名字]]`
		比如[[Git#文件的四种状态|转到Git文档中的文档的四种状态]]
代码如下
```markdown
[[Git#文件的四种状态|转到Git文档中的文档的四种状态]]
```

## 锚点链接的使用
可以用于在一篇长文中进行跳转
[查看Markdown格式的介绍](#Markdown介绍)
```markdown
这是代码格式
[查看Markdown格式的介绍](#Markdown介绍)
```
*标题会自动生成锚点*

# Markdown 图片
***
在markdown格式中插入图片可以使用`![图片名字](图片路径"注释这一块")`的格式来创建
**相对路径**
相对路径以当前笔记或 Vault 根目录为参照，笔记整体移动后仍有机会保持有效。
**绝对路径**
绝对路径通常从盘符开始，例如 `D:\Obsidian\Obsidian_slide\attachments\image.png`；缺点是 Vault 移动或换电脑后会失效。
>*推荐使用 Vault 相对路径或 Obsidian 附件短链接*
>可以把附件统一放在 `attachments` 文件夹中

也可以使用网络图片，后面地址改成网址就行
也可以像网址那样，把后面`()`变成`[]`,然后在文后写注释一样

# Markdown 表格
***
Markdown 制作表格使用`|` 来分隔不同的单元格，使用 `-` 来分隔表头和其他行。
```markdown
|  表头   | 表头  |
|  ----  | ----  |
| 单元格  | 单元格 |
| 单元格  | 单元格 |
```

|  表头   | 表头  |
|  ----  | ----  |
| 单元格  | 单元格 |
| 单元格  | 单元格 |
## 对齐方式

**我们可以设置表格的对齐方式：**

- ---: 设置内容和标题栏居右对齐。
- :--- 设置内容和标题栏居左对齐。
- :---: 设置内容和标题栏居中对齐。
```markdown
| 左对齐的单元格 | 右对齐的的单元格 | 居中对齐的单元格 |
| :------ | -------: | :------: |
| 单元格     |      单元格 |   单元格    |
| 单元格     |      单元格 |   单元格    |
```

| 左对齐的单元格 | 右对齐的的单元格 | 居中对齐的单元格 |
| :------ | -------: | :------: |
| 单元格     |      单元格 |   单元格    |
| 单元格     |      单元格 |   单元格    |
## 表格内也支持写语法

```markdown
| A | B | C |
| -----| ---- | ---- |
| *斜体* | **粗体** | ***粗斜体*** |
```

| A    | B      | C         |
| ---- | ------ | --------- |
| *斜体* | **粗体** | ***粗斜体*** |
还可以使用链接等

# Markdown高级技巧
***
## 支持的HTML元素
不在Markdown涵盖范围内的标签，都可以在文档中使用HTML编写
支持的元素有`<kbd>, <b>,<i>,<em>,<sup>,<sub>,<br>`等
such as
```HTML
使用<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Esc</kbd>打开任务管理器
```
使用<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Esc</kbd>打开任务管理器

## 转义
在Markdown中使用`\`来表示符号原来的形态
*斜体*
\*斜体*
```markdown
*斜体*
\*斜体*
```
这一点和Python一样

## 公式
Markdown中支持使用KaTeX或MathJax来渲染数学公式。
* 使用`$...$`中的数学表达式在行内显示
* 使用`$$...$$`中的数学表达式在块内显示
$$
\begin{Bmatrix}
	a & b \\
	c & d
\end{Bmatrix}
$$
```markdown
$$
\begin{Bmatrix}
	a & b \\
	c & d
\end{Bmatrix}
$$
```
