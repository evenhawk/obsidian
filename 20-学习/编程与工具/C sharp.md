C# 是**完全**的面向对象编程语言，而且还不是顺序执行，类和方法定义可以放在主类后面

## C# 文件后缀

- `.cs` 源代码文件存放类、结构体、枚举、接口等，是最核心文件。
- `.sln` *solution* 解决方案文件，用来组织多个项目
- `.csproj` C#项目文件，定义引用、输出、编译选项、SDK
- `.exe` 可执行程序
- `bin` 编译文件夹，存放编译产物
- `.xml` 注释文档

## 命名空间

命名空间(namespace)：命名空间就是用来给类型划分区域，避免类名冲突，同时方便组织代码的容器。

使用 `using` 来导入命名空间

## 数据类型

C# 的数据类型大致分为两种

1. **值类型**
   - 简单值类型
   - 结构 structure
   - 枚举 enum
2. **引用类型**
   - Object
   - 类类型 class
   - 接口 interface
   - 字符串 string
   - 数组 array
   - 委托 delegate

注意：

1. 双引号 `"string"`，单引号 `'char'`
2. 数据类型转换可以使用 `Convert` 类提供的静态方法实现
3. 枚举值默认从0开始，如果有赋值，索引会跳转到赋值

## 访问修饰符

在C#中访问修饰符一共有五种

1. `public`
2. `protected`
3. `internal`
4. `protected internal`
5. `private`

| 修饰符 | 访问范围 |  |
| --- | --- | --- |
| `public` | 任何地方都可以访问 | 所有人 |
| `protected` | 当前类 + 子类（不管是否同程序集） | 自己+儿子 |
| `internal` | 当前程序集（同一个项目）内任意地方 | 自己项目 |
| `protected internal` | 当前程序集，或者别的程序集中的子类 | 自己+外地儿子 |
| `private` | 仅当前类内部（默认） | 只有自己 |

## static关键字

用于修饰类/字段/属性/方法/构造方法等

被修饰的成员称为**静态成员**,被修饰的类称为**静态类**

被 `static` 修饰的静态成员==不能用类的实例来访问==

使用:当一个属性属于这个类而不是实例的时候就应该设置为静态成员

`类名.静态字段名`

当一个类的所有成员都是静态成员时,可以把这个类声明为静态类

**特点:**

1. 静态类只包含静态成员
2. 静态类不能被实例化
3. 静态类是密封的
4. 静态类不能包含实例的构造方法

## 方法

### 方法的定义

```csharp
[访问修饰符] 返回值类型 方法名 (参数列表)
{
   方法体
   [return 返回值;]
}
```

### 方法的重载

方法的重载就是一个方法根据接收参数的数量，写多个共用一个函数名但是参数不同的函数。

如果参数相同的话可以在后面加一个 `bool` 量判断

### 方法的高级参数

1. `params` 可以传入任意数量的参数
2. `ref` 保留方法内部的变量的修改
3. `out` 用于将方法中的值定义扩散到方法体外,直接在外面使用

```csharp
// 重载 1：圆形，一个参数
static double GetArea(double radius)
{
    return Math.PI * radius * radius;
}

// 重载 2：矩形，两个参数
static double GetArea(double length, double width)
{
    return length * width;
}

// 重载 3：三角形，三个参数（第三个仅用来区分签名）
static double GetArea(double bottom, double height, bool isTriangle)
{
    return bottom * height / 2;
}
```

## 面向对象的基本特征

### 类的继承

**特点:**

1. 只能继承一个基类,但是可以实现多个接口
2. 子类可以继承成员但不能继承构造方法
3. 类的继承可以传递

### 多态

多态 = “同一个引用类型，指向不同实际对象，调用同一个方法，跑出不一样行为”；**虚方法**就是 C# 实现这个机制的载体。

#### 虚方法

发生在继承体系中,方法和参数等一样,可以在子类中重写的方法

父类定义使用 `virtual`

子类重写使用 `override`

### 抽象类和嵌套类

#### 抽象类

抽象类是修饰类，用来做基类，放抽象契约 + 共用代码，==不能直接实例化==

1. 可以有抽象成员、普通成员、虚方法、构造函数
2. 只能被继承
3. 构造函数可以有，但只能给子类调用

抽象成员的实现只能由继承后的子类实现,抽象类本身不实现抽象方法

#### 嵌套类

位置概念，写在另一个类内部的类

| 对比 | `abstract class` | `static class` |
| --- | --- | --- |
| 实例化 | 不能直接 new；由子类 new | 完全不能 new，永远没有实例 |
| 继承 | 可以被继承；自身也可以继承别的类 | 不能被继承，也不能继承任何类（隐式继承 object，但不能写） |
| 成员 | 可以有实例成员、静态成员、抽象成员、构造 | 只能包含静态成员 |
| 构造函数 | 有构造（protected，给子类） | 编译器自动生成私有无参构造，无法调用 |
| 是否可以实现接口 | ✅ 可以实现接口 | ❌ 不能实现接口 |
| 使用场景 | 抽取子类共用逻辑，定义必须实现的抽象方法 | 工具类，一堆静态方法（Math、Enumerable） |

**相同点:**

1. 都不能直接实例化
2. 都可以拥有静态成员

#### 虚方法对比抽象成员

**相同点:**

1. 都用于继承,子类都使用 `override` 重写
2. 都可以被子类改写行为。

```csharp
abstract class Base
{
    public virtual void Hello()
    {
        Console.WriteLine("虚方法默认");
    }
    public abstract void Work();
}
class Sub : Base
{
    // Hello：可写可不写
    // Work：必须写
    public override void Work(){}
}
```

| 对比 | `virtual` 虚方法 | `abstract` 抽象成员 |
| --- | --- | --- |
| 方法体 | 必须有默认实现 | 无方法体，不能写实现 |
| 所在类 | 普通类 / 抽象类都可以 | 只能放在抽象类 / 接口 |
| 子类 | 可选重写，不改就用基类版本 | 非抽象子类必须实现 |
| 能不能 new 包含它的类 | 如果是普通类，可以直接 new | 包含它的类一定不能直接 new |
| 关键字 | virtual；子类 override | abstract；子类 override |

#### interface对比abstract

**相同点:**

1. 都是一种契约,要求实现者提供逻辑
2. 最终实例必须补齐全部未实现成员，否则编译报错。
3. 都支持多态。

```csharp
abstract class Animal
{
    protected string name;
    public abstract void Speak();
}
interface ISpeak
{
    void Speak();
}
```

| 对比 | 抽象类中的 `abstract` 成员 | 接口成员（C# 默认） |
| --- | --- | --- |
| 载体 | 抽象类 | interface |
| 继承规则 | 类只能继承一个抽象类 | 一个类可以实现多个接口 |
| 是否有字段 | 抽象类可以有字段、构造函数 | 不能有实例字段、不能有构造 |
| 默认实现 | 无（抽象成员本身） | C#8+ 接口可以写默认实现 |
| 访问修饰 | 可以用 public /protected/internal 等 | 默认 public，不能写 protected /private（常规） |
| 关系 | “是一个（is-a）” | “具备某种能力（can-do）” |
| 静态成员 | abstract 实例成员不能 static | .NET6+ 支持 static abstract |

### 委托与Lambda表达式

#### 委托

委托代表了对方法的引用

使用关键字 `delegate` 来声明

**格式:**

```csharp
[访问修饰符]delegate 返回值类型 委托名({形式化参数列表});
```

**特点:**

1. 委托类似于C++的函数指针,但与指针不同的是,委托是完全面向对象的,是安全的数据类型
2. 委托允许将方法作为参数进行传递
3. 委托可用于定义回调方法
4. 委托可以把多个方法连接在一起,这样在事件触发的时候可同时启动多个事件处理程序

#### lambda表达式

本质**匿名方法**

**格式:**

```csharp
(参数列表) =>{语句序列}
```
