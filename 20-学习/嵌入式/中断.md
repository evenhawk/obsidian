# 中断
中断就是打断正常程序执行流程,去执行另外一个更加紧急的任务
中断处理的三个步骤
1. 保存现场
2. 调用中断服务程序
3. 恢复现场
外部中断/事件控制器框图:
![[Pasted image 20261123080819.png]]
这样的控制器一共有19个,都使用同一套寄存器
前16个EXTI1~EXTI15,对应GPIO口

型号通过GPIO进入输入线,先经过边沿检测电路和上升沿/下降沿触发选择寄存器判断向后输出一个高电平还是低电平
经过一个或门,所以电路的电平变化和软件的中断都会传递到下一步
请求挂起寄存器收到高电平后会将对应位置1,然后输出到一个与门
所以中断屏蔽寄存器可以屏蔽中断信号
只有中断屏蔽寄存器的对应位为1才能通过与门,到达NVIC

*中断和事件的区别在于中断调用代码处理,事件把中断事件送到相应的外设*
# NVIC
NVIC全程嵌套中断向量控制器
用于管理中断向量表和优先级
每一个中断向量都指向一个中断处理函数`EXTI<X>_IRQHandler`
在中断向量表中EXTI0~EXTI4拥有自己的中断向量
EXTI5~9和EXTI10~15分别共用一个中断向量(可以通过标志位判断是具体哪个触发了中断)
**中断服务程序最后一步需要把请求挂起寄存器的对应位清零**
是内核外设

# 中断优先级
中断的优先级分为抢占优先级和子优先级
中断数值越小优先级越高

抢占优先级决定了执行的优先级和打断别的中断的能力

子优先级又称响应优先级
在抢占优先级相同的情况下,子优先级越高越先执行
子优先级一致的话看中断向量表的硬件序号来决定(IRQn)

配置中断优先级的寄存器有四个位
需要先配置抢占优先级和子优先级各占几个位
