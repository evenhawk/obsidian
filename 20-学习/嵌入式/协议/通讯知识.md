# 通讯知识

## 一、串行通信与并行通信

根据数据的传输方式，通信分为**串行通信**和**并行通信**。

并行通信表示几个数据一起传，使用多根线；串行通信表示数据一位一位地传输，使用单根线。

**特性对比**

| 对比项 | 串行通信 | 并行通信 |
| --- | --- | --- |
| 传输方式 | 数据一位一位传输 | 几个数据一起传 |
| 线数 | 单根 | 多根 |
| 通信距离 | **远** | 近 |
| 抗干扰能力 | **强** | 弱 |
| 传输速率 | 慢 | **快** |
| 成本 | **低** | 高 |

**常见设备**

| 类型 | 设备 |
| --- | --- |
| 串行 | USART、I2C、SPI |
| 并行 | SDIO、FSMC（控制液晶或 SRAM）、W5500 |

*提示：串行的优势是距离远、抗干扰强、成本低，并行的优势是速度快。所以片内高速互连（LCD、SRAM）用并行，板间或设备间通信用串行。*

## 二、通信方向：单工、半双工、全双工

通信的方向分为全双工、半双工和单工。

| 模式 | 线数 | 能否同时收发 | 数据方向 | 例子 |
| --- | --- | --- | --- | --- |
| **全双工** | 两根 | 可以同时发送和接收 | 双向 | USART、SPI |
| **半双工** | 两根 | 不可以同时发送和接收 | 双向，但分时 | I2C、RS485 |
| **单工** | 一根 | 不需要 | 固定单向 | 遥控器、广播 |

*提示：判断分两步。先看能不能同时收发，不能就是半双工；再看方向是否固定，固定就是单工。*

## 三、同步与异步

> 只要有时钟信号就是同步通信，没有时钟信号都是异步通信。

| 对比项 | 同步通信 | 异步通信 |
| --- | --- | --- |
| 时钟信号 | **有**，周期性方波 | **无** |
| 数据交换时刻 | 时钟信号的特定时刻 | 起始位、停止位对齐 |
| 双方约定 | 共用同一个时钟 | 约定相同的**波特率** |
| 帧开销 | 小 | 大（起始位、校验位、停止位） |
| 例子 | I2C、SPI | USART（异步模式） |

*提示：异步帧里起始位和停止位是必需的，奇偶校验位是可选的。*

## 四、通信速率：比特率与波特率

| 名称 | 定义 | 单位 |
| --- | --- | --- |
| **比特率** | 每秒传输的**二进制位数** | bit/s（bps） |
| **波特率** | 每秒传输的**码元个数** | Baud |

一般时候比特率就是波特率，除非一个码元携带的位数不为一。

也就是说，一个码元只表示 1 bit 时，比特率等于波特率；一个码元能表示多个 bit 时，两者不等。

**一个码元 = 1 bit（比特率 = 波特率）**

| 电平 | 表示 |
| --- | --- |
| 0 V | 0 |
| 3.3 V | 1 |

**一个码元 = 2 bit（比特率 = 2 × 波特率）**

| 电平 | 表示 |
| --- | --- |
| 0 V | 00 |
| 2 V | 01 |
| 4 V | 10 |
| 5 V | 11 |

*提示：换算关系是比特率 = 波特率 × 每个码元的比特数。第二种情况若波特率为 1 Baud，比特率就是 2 bit/s。*

## 复习速查

| 问题 | 答案 |
| --- | --- |
| 串行和并行怎么分 | 数据是一位一位传，还是几位一起传；也就是看线数 |
| 串行的三个优势 | 距离远、抗干扰强、成本低 |
| 全双工和半双工怎么分 | 能不能同时收发 |
| 单工和半双工怎么分 | 数据方向是否固定 |
| 同步和异步怎么分 | 有没有时钟信号 |
| 异步靠什么同步 | 起始位、停止位，加上双方约定的波特率 |
| 比特率和波特率何时相等 | 一个码元只携带 1 bit 时 |
| 换算公式 | 比特率 = 波特率 × 每码元比特数 |
