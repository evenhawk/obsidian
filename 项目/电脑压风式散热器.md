# 目标
使用离心风扇作为主要部件,使用ESP32S3N16R16开发板来进行开发
实现的目标:
1. 风扇的驱动
2. ESP32通过调节风扇PWM来实现调速功能
3. 通过WiFi TCP加上电脑上位机在OLED屏幕上显示当前电脑状态
4. 加上按键来手动控制PWM占空比
5. 模式设置:安静/自动/手动/停止
